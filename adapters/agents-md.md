# 어댑터 · AGENTS.md 계열

AI용. `AGENTS.md`를 상시 지침으로 읽는 에이전트 도구에 쓴다.

- **계열 전체 열**은 이 계열에 공통이라고 이 저장소가 확인한 것만 적는다. 대부분 확인하지 않았다.
- **Codex 열**은 한 도구의 사실이다. OpenAI 공식 문서(learn.chatgpt.com의 AGENTS.md · Permissions · Memories · Hooks 문서)로 확인한 날을 적었고, 실제 실행에서 관찰한 것은 따로 표시했다. 도구 버전이 바뀌면 달라질 수 있다 — 사실로 단정하기 전에 사용자 환경에서 다시 본다.

**기억을 수동으로 운용하려면** — 도구의 기억 기능과 별개로, 이 저장소가 권하는 운용법이다(도구 기능이 아니다): 작업 폴더에 `MEMORY.md`(한 줄 인덱스)와 사실 하나당 파일 하나를 두고, 지침 파일에 "세션을 시작하면 MEMORY.md를 읽는다"를 적는다. 도구가 이 파일을 스스로 찾지 않으므로 지침 문장이 없으면 읽히지 않는다.

## AI-START 적용 메모

- **TBD 칸을 추측으로 채우지 않는다.** 사용자 도구의 문서를 확인하거나 사용자에게 묻는다.
- 확인이 안 되면, 넣는 형태가 `설정`·`훅`인 gate는 **지침 파일의 문장**으로만 제안한다. 절차는 도구 기능 없이 문장만으로도 성립하게 쓴다.
- **Codex에서 상시 지침을 읽을 때:** 작업 폴더의 `AGENTS.md`만이 아니라 `AGENTS.override.md`와 전역(`~/.codex`) 파일까지 "읽은 것"에 적는다. override 파일이 있으면 그쪽이 이긴다 — 진단표의 "있음 · 없음"은 이긴 쪽을 기준으로 판정한다.
- **판을 웹 조회로 읽으면 옛 판이 올 수 있다** — Codex 실행에서 공개본 맨 위보다 한 판 앞선 CHANGELOG를 받은 기록이 있다(2026-09-26). 출력 머리의 기준 판 옆에 읽은 경로를 적고, 표시를 붙이기 전에 한 번 더 확인한다.
- **automation 트랙:** 스케줄러·서비스 등록, 재시도 옵션, 실행 시간 제한은 운영체제의 사실이다. 사용자 운영체제의 문서로 확인하게 하고 추측으로 채우지 않는다.
- 이 저장소를 사용자 작업 폴더 안에 받지 않게 한다 — 같은 이유로 진입점 이름이 `AGENTS.md`가 아니다.
