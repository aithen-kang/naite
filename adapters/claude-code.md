## AI-START 적용 메모

- **단계 1에서 읽을 곳:** 루트 `CLAUDE.md` → 권한 파일 세 곳(있는 것만) → 기억 인덱스(있으면).
- **단계 6:** 권한·훅 설정을 바꿨다면 "새 세션에서 확인"을 사용자에게 알린다.
- **setup 트랙:** 공통 권한 규칙을 전역 설정에 두는 설계라면 전역이 정본이고, 프로젝트 파일로만 운영한다면 두 프로젝트 파일에 같은 규칙을 적는다. 사용자가 어느 쪽인지 먼저 확인한다. 대화 기록을 오래 남겨야 하는 사용자라면 보존 기간 설정값도 확인한다.
- **automation 트랙:** 스케줄러·서비스 등록, 재시도 옵션, 실행 시간 제한은 이 도구가 아니라 운영체제의 사실이다. 이 저장소는 그 사실을 확인일과 함께 갖고 있지 않으니, 제안할 때 사용자 운영체제의 문서로 확인하게 한다. 이 도구를 무인으로 실행하는 봇·액터(AUTO-20 · 23)라면 무인 실행의 권한을 대화형 세션보다 좁게 두게 한다.
- **권한 규칙을 제안할 때:** 와일드카드·도구명 단독 허용이 기대와 다르게 매칭된 기록이 있다(2026-08-08). 규칙을 넣은 뒤 새 세션에서 실제 명령 한 번으로 확인하게 한다.
- **공통 규칙이 프로젝트 설정에만 있으면**, 작업 폴더 밖에서 연 세션에는 적용되지 않는다. 사용자가 여러 폴더에서 세션을 연다면 스코프(전역/프로젝트)부터 확인한다.
- **이 저장소를 사용자 작업 폴더 안에 받지 않게 한다.** 하위 폴더의 지침 파일이 함께 읽힐 수 있다 `[⚠️ AI추론·신뢰도 보통 — 버전 의존]`. 이 저장소의 진입점 이름이 `CLAUDE.md`가 아닌 이유다.
