# kit · three-models — 불확실한 추정을 범위로 답하는 틀

- **조건:** 정책 효과·영향 규모처럼 하나의 숫자로 답하면 그 가정이 무너질 때 분석 전체가 불신받는 질문을 받았다
- **도구 의존:** 없음
- **쓰는 ID:** NUM-17

## 1. 규율

- 각 모델의 **가정을 한 줄로** 적는다. 가정 없는 시나리오는 그냥 임의의 숫자다.
- **현실 모델을 기본 답으로**, 비관과 상한은 범위의 양 끝으로 준다.
- **현실이 비관으로 미끄러지는 조건**을 적는다. 추정이 나중에 빗나가도 분석의 신뢰가 유지된다.
- 세 숫자의 **간격 자체가 의사결정 정보**인지 본다 — 예: 상한과 현실의 차이가 "다른 방식으로 구현할 가치"다.

## 2. 보고 틀

```markdown
## {질문} — 추정 범위

| 모델 | 값 | 가정 |
|---|---|---|
| 현실 (기본 답) | {값} | {한 줄} |
| 비관 | {값} | {한 줄} |
| 상한 | {값} | {한 줄} |

- 현실이 비관으로 미끄러지는 조건: {한 줄}
- 세 값의 간격이 말하는 것: {한 줄 — 무엇을 결정하는 데 쓰나}
- 기준: {데이터 기간 · 정의 · 추정에 쓴 관측}
```

## 3. 보고 문장 예

```
{조치 A}로는 {현실 값} 수준까지 기대할 수 있지만, {미끄러지는 조건}이 진행되면 {비관 값}까지 떨어질 수 있습니다.
{조치 B}는 그 조건과 무관하게 {상한 값}을 보장합니다.
```
