# kit · env-template — 값을 비운 환경 파일 템플릿

- **조건:** 자격증명을 환경 파일 하나에 모으고, 그 파일을 공유하지 않는다
- **도구 의존:** 없음 (셸 `source` 호환 형식)
- **쓰는 ID:** SETUP-08 · SETUP-09

실제 값이 든 환경 파일은 어떤 공유·백업·커밋에도 넣지 않는다. 대신 **같은 구조에 값만 비운 템플릿**(`env.example`)을 둔다. 템플릿의 가치는 주석에 있다 — 자격증명은 종류마다 수명이 달라서, 발급 경로와 만료 주기가 적혀 있지 않으면 만료될 때마다 "왜 안 되지"를 처음부터 겪는다.

```bash
# ─── {외부 서비스 A} — 영구 키 ─────────────────────────
# 발급: {서비스 설정 화면} → API 키
# 만료: 없음 — 유출되면 재발급
export SERVICE_A_KEY=''
export SERVICE_A_BASE='https://{service-host}'

# ─── {서비스 B} — OAuth, 7일 만료 ──────────────────────
# 발급: {콘솔 경로}
# 갱신: {갱신 명령 또는 절차}
export SERVICE_B_CLIENT_ID=''
export SERVICE_B_REFRESH=''

# ─── {내부 시스템 C} — 세션 쿠키, 8시간 만료 ────────────
# 갱신: {갱신 절차}
export SYSTEM_C_BASE='https://{internal-host}'
export SYSTEM_C_COOKIES=''

# ─── (폐기 예정 — 구버전 호환, 새 환경에서는 지운다) ──────
```

## 지킬 것

- **템플릿에 실제 값을 넣지 않는다.** "공용 계정이라 그대로 써도 된다"는 이유도 예외가 아니다. 템플릿은 정의상 공유 파일이고, 공용 계정도 자격증명이다.
- **키를 바꿀 때는 새 줄을 추가하지 않고 기존 줄을 고친다.** 단순한 로더는 마지막 선언을 조용히 채택한다.
- **정비할 때 중복 키를 한 번 검사한다.** 값은 출력하지 않고 키 이름만 본다.

```bash
grep -oE '^\s*(export\s+)?[A-Z_][A-Z0-9_]*=' .env | sed -E 's/^\s*(export\s+)?//; s/=$//' | sort | uniq -d
```

아무것도 출력되지 않으면 중복이 없다. `.env`는 환경 파일의 실제 경로로 바꾼다.

- **값이 있는지만 확인하면 되는 상황에서는 값을 가려서 본다.**

```bash
sed -E 's/=.*/=********/' .env
```
