# kit · doc-header — AI 작성 규칙 머리 블록

- **조건:** 한 문서를 여러 세션에 걸쳐 AI와 쓰고, 그 문서를 참조해 다른 산출물을 만든다
- **도구 의존:** 없음
- **쓰는 ID:** SPEC-01 · SPEC-07

문서 맨 위에 붙이고 `{ }`만 바꾼다. 규칙을 사람의 기억이 아니라 문서 자체에 박아 두면, 어떤 세션에서 누가 이 파일을 열어도 같은 안전장치가 작동한다.

```markdown
> **AI 작성 규칙 (이 파일을 AI와 함께 작성할 때)**
> - **1단계:** {뼈대 — 예: 상태값 표와 항목 목록}만 먼저 쓴다. 상세는 비워 둔다. → 사용자 검토
> - **2단계:** 사용자가 확정한 뒤 항목별 상세를 쓴다. 1단계에서 확정한 구조를 임의로 바꾸지 않는다 — 바꿔야 하면 먼저 제안한다.
> - 이 파일에 정의되지 않은 항목은 `[⚠️ TBD]`로 둔다. 임의로 판단하거나 만들지 않는다.
> - AI의 역할은 정해진 내용을 표현하는 것이다. 옳고 그름의 판단, 우선순위 결정, 미정 항목의 생성은 AI의 역할이 아니다.
> - 이 파일을 참조해 다른 산출물을 만들 때, 아래 성숙도가 "초안"인 섹션은 `[⚠️ TBD]`로 처리한다.

## 섹션 성숙도

| 섹션 | 상태 | 최종 갱신 |
|---|---|---|
| {섹션 이름} | 확정 / 초안 / 해당없음 | {YYYY-MM-DD} |
```

마지막 두 줄이 핵심이다. **역할 선언**(표현이 역할이지 판단이 역할이 아니다)과 **성숙도 게이트**(초안은 미확정 취급)가 빠지면, 초안 단계의 임시 결정이 다음 산출물에 확정처럼 퍼진다.

| 상태 | 뜻 |
|---|---|
| 확정 | 후속 작업에서 참조할 수 있다 |
| 초안 | 후속 작업에서 `[⚠️ TBD]`로 처리한다. 참조하지 않는다 |
| 해당없음 | 이 문서에 해당 섹션이 없다 |
