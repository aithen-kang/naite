# kit · tags — 미정·AI 추가 표시와 근거 표시

- **조건:** 원본(자료·결정·시스템)이 있는 문서를 AI가 쓰거나 정비하고, 누군가 표시를 검색해 확인한다
- **도구 의존:** 없음
- **쓰는 ID:** SPEC-06 · SPEC-14

## 1. 기본 — 모든 사용자

| 표시 | 뜻 | 어떻게 풀리나 |
|---|---|---|
| `[⚠️ TBD]` | 미정. 아직 아무도 정하지 않았다 | 결정할 사람에게 넘긴다. 미정 목록에 모은다 |
| `[⚠️ AI추론]` | 원본에 없는 것을 AI가 보탰다 | 확인할 사람에게 넘긴다. 확인 뒤 표시를 지우거나 문장을 지운다 |
| `[⚠️ CROSS: {단위}]` (선택) | 다른 단위에서 먼저 확정돼야 하는 의존 | 그 단위를 작업할 때 이 표시를 검색해 푼다 |

**파생값은 원 진술의 표시를 물려받지 않는다.** 원문에서 계산하거나 끌어낸 값 — 요일·기간·합계, 긍정 진술에서 끌어낸 "~는 해당 없다" — 은 원문의 확인 표시 아래 두지 않고 따로 `[⚠️ AI추론]`을 붙인다.

지침 파일에 넣는 문장:

```markdown
## 모르는 것과 보탠 것
- 자료에 없는 것은 지어내지 않고 [⚠️ TBD]로 둔다.
- 자료에 없는 것을 보탰으면 [⚠️ AI추론]을 붙인다.
- 원문에서 계산하거나 끌어낸 값(요일·기간·합계·"해당 없음")은 원문의 표시를 물려받지 않는다 — 따로 표시한다.
- 시스템·데이터에서 확인한 사실에는 확인한 날짜를 붙인다.
```

v1.0을 선언하는 기준은 "미정 0건"이 아니라 **"몰라서 비어 있는 것 0건"**이다. 알지만 아직 안 정한 것은 v1.0에도 남을 수 있다.

## 2. 확장 단계 — 근거 표시 5종

**조건:** 같은 사실에 대해 출처가 둘 이상 있고(시스템·담당자·문서·AI 산출물), 서로 어긋날 수 있다. **처음부터 넣지 않는다** — 이 표시 체계도 처음에는 표시 하나에서 시작해 운영 중에 다섯으로 늘었다. 기본 표시가 자리 잡은 뒤, 출처 충돌을 실제로 겪었을 때 제안한다.

| 표시 | 뜻 | 서열 |
|---|---|---|
| `[실측: 대상·YYYY-MM-DD]` | 시스템·데이터·코드에서 직접 확인 | 1 (최상) |
| `[확인: 주체·YYYY-MM-DD]` | 확정 권한이 있는 사람의 직접 확답 | 2 |
| `[근거: 문서#위치]` | 원본 문서·위키·티켓에서 확인 | 3 |
| `[AI산출 유래: 파일·YYYY-MM-DD]` | AI가 만든 산출물(프로토타입·요약)에서 가져온 사실 | 4 |
| `[⚠️ AI추론]` | 위 근거가 없는 추론. 중요 판단이면 `·신뢰도 높음/보통/낮음` | 5 (최하) |

운용 원칙:

1. **충돌하면 서열대로 판정한다 — 실측이 문서를 이긴다.** 문서는 낡을 수 있지만 실측은 지금의 사실이다.
2. **서열을 적용하기 전에 두 진술이 같은 질문·같은 축에 답하는지 본다.** 시점·매체·장소·주체가 다른 진술은 대체가 아니라 합성이다. 둘 다 답하지 않는 질문에 서열을 적용하면 오답이 근거 등급을 입는다.
3. **충돌을 발견하면 한쪽을 지우지 않는다.** 양쪽을 병기하고 `[⚠️ 문서 갱신 필요]`를 남긴다. AI가 조용히 한쪽을 고르면 사람은 충돌이 있었다는 사실 자체를 모른다.
4. **`[AI산출 유래]`는 원본 사실과 AI가 채운 값이 한 산출물에 같은 형식으로 섞여 있을 때만 쓴다.** 그걸 `[근거:]`로 적으면 AI가 채운 값이 사실로 승격된다. 섞이지 않은 순수 기계 산출물(수집 결과 파일)은 `[실측:]`이다.
5. **날짜 없는 실측·확인은 쓰지 않는다.** 낡은 문서의 근본 결함은 틀린 내용이 아니라 언제 기준인지 알 수 없다는 것이다.

이 표시를 문서를 읽는 AI의 실행 규칙으로도 쓸 수 있다 — 예: "`[AI산출 유래]`·`[⚠️ AI추론]`이 붙은 값은 구현하지 않는다."
